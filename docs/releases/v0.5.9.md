# seek v0.5.9

## Highlights

- **Multi-agent code review remediation:** addresses high-impact findings across chunking, indexer orphan cleanup safety, embedding client guards, and hybrid search RRF fusion.

## Fixes

- **Chunking (UTF-8 safety):**
  - UTF-8-safe overlap truncation (`tailBytes`) avoids slicing multibyte runes when trimming overlap, which previously produced invalid UTF-8 in chunk content and miscounted chunk boundaries.
  - Safe UTF-8 truncation in snippet generation and CLI string truncation helpers.
- **Indexer (orphan cleanup safety):**
  - Added `safeCleanupOrphans` guard across all collection handlers (markdown, code, conversations, media, documents, parser collections) ensuring scans only purge when the scan root exists as a directory. Unmounted drives or missing directories no longer wipe existing collections.
- **Embeddings & Providers (security & robustness):**
  - Enforced loopback IP verification directly in `VLClient` to prevent egress bypass when `privacy.offline_only` is enabled.
  - Bounded non-2xx error response bodies to 2 KiB across text, multimodal (VL), reranker, OCR, and batch clients to prevent uncontrolled error log pollution.
  - Fast error termination for batch job polling on non-200 HTTP responses.
- **Search (result fidelity):**
  - Hybrid RRF fusion now preserves richer full-chunk candidates (`ChunkID > 0`) over 40-token BM25 snippets for shared document hits, retaining full content and line span accuracy.

## Validation

- Full test suite, `go vet`, and `gofmt` verified with CGO and FTS5 tags (`-tags "fts5 sqlite_fts5"`).
- Regression tests added covering UTF-8 chunk tails, directory existence guards, batch poll error handling, and multi-vector-chunk hybrid fusion ranking.

## Upgrade notes

Patch release; drop-in binary replacement. No index schema migrations or vector space changes required.

# seek v0.5.6

## Highlights

- Forced re-embedding no longer mutates the live HNSW graph chunk by chunk,
  preventing duplicate-node panics from `coder/hnsw`.
- Full vector rebuilds are now atomic: seek constructs a complete candidate
  graph and publishes it only after every persisted embedding is accepted.
- Failed rebuilds preserve the previous searchable graph, and failed updates
  restore the prior SQLite embedding to avoid database/index divergence.

## Validation

- Reindexed the seek repository with the local Ollama embedding provider:
  2,255 of 2,255 chunks embedded and the HNSW index synchronized successfully.
- Confirmed vector search returns results from the rebuilt index.
- Passed the full FTS5-tagged Go test suite, `go vet`, formatting, and diff
  checks on Windows with Zig CGO.

## Upgrade notes

This is a patch release. Existing installations can use the standard installer.
If a previous failed re-embedding left the vector graph incomplete, rebuild the
collection after upgrading:

```text
seek collection reindex <collection> --allow-vector-space-change
```

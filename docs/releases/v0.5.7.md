# seek v0.5.7

## Highlights

- Code chunking correctness: overlap tails between code chunks are no longer
  written in reversed line order, oversized lines split at UTF-8 rune
  boundaries, and line spans no longer collapse — indexed code snippets match
  the source again.
- Silent-failure hardening across the store, embedding clients, and CLI:
  FTS rebuilds and collection deletion run in real transactions, HNSW search
  errors propagate instead of degrading silently, and a crashed tokenizer
  migration heals itself instead of leaving keyword search empty forever.
- Secret hygiene: `seek config` and `seek doctor --verbose` mask API keys,
  and `seek auth login` preserves `${VAR}` indirection instead of baking
  plaintext secrets (and stale OCR/Rerank fallback keys) into config.yaml.
- Ctrl+C now unwinds long-running commands through cleanup instead of killing
  the process mid-write.
- Local semantic NLP service: setup scripts, model bootstrap, and quickstart
  docs for the optional `tools/semantic` tag enrichment service.

## Validation

- Full FTS5-tagged Go test suite, `go vet`, and formatting checks pass on
  Windows with Zig CGO; the review cycle was verified by independent
  code-review and silent-failure audit passes.
- End-to-end on the seek repository itself: sync indexed 62 changed files and
  embedded 721/721 chunks through the local Ollama provider, semantic backfill
  processed 259/259 documents (LID + NER + keyphrases + topics) with zero
  failures, and hybrid search with reranking returned correctly scoped
  results.

## Upgrade notes

This is a patch release. Existing installations can use the standard
installer.

Code collections indexed before this version may contain scrambled overlap
text and mid-rune fragments. Rebuild them after upgrading:

```text
seek collection reindex <code-collection>
```

Behavior refinements to be aware of: the parsed query mode now rejects
unrecognized punctuation instead of silently dropping it (raw-mode fallback
still applies), sync/embed progress and per-collection errors are logged to
stderr (result lines remain on stdout), and an aborted `seek auth login`
exits non-zero so automation can detect cancellation.

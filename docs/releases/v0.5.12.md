# seek v0.5.12

## Highlights

- **Safer macOS service install:** `seek service start` verifies the launchd plist was written and flushed successfully before registering it with `launchctl`, so a disk-level failure can no longer silently install a broken service definition.
- **Architecture is now enforced, not just documented:** a package layering guard runs on every `go test` and fails on import cycles, upward imports, or `third_party` reaching back into the main module.
- **Skill service scripts are a generated artifact:** the `skills/seek/scripts/services/` mirror of the optional Python services is guarded by an SSOT test — drift, hand-edits, and unlisted files fail `go test` with a remediation hint instead of requiring every fix to be applied twice.

## Fixed

- **launchd plist close (`cmd/service.go`):** `startDarwinService` now checks the error from closing the plist file before `launchctl bootstrap`; previously a failed flush truncated the plist silently. Also drops an unused `launchctl print` output variable in the status command.
- **Line endings for mirrored service scripts:** `tools/{semantic,xberg_server,flashrank_server,embed_server}` and `skills/seek/scripts/services/` are pinned `eol=lf` in `.gitattributes` (the same convention as the golden help files). On `core.autocrlf=true` Windows checkouts this prevents git from rewriting `setup.sh` to CRLF — a latent breakage — and keeps the byte-based bundle comparison stable.

## Refactoring

- **`syncConversation` (`internal/indexer/indexer.go`):** the ~200-line shared Claude/Codex conversation sync path is decomposed into `conversationTitle`, `buildConversationChunks`, `pruneEmptyConversationBatch`, `conversationBaseSeq`, and `writeConversationDocument`. Behavior is preserved exactly: same WARN messages, same failure counters, same error returns, same sequence numbering and line-span offsets. The append base-seq error path and the empty-batch pruning contract are pinned by new unit tests against a real temp SQLite store.

## Tests

- `layering_test.go`: import-graph guard via `go list -json` — cycles, layer directions (root → cmd → internal), renameio-leaf rule; includes a non-vacuous guard against `go list` returning zero packages.
- `TestSkillServiceBundleIsSynchronized`: parses the pair list from `scripts/sync-skill-services.py` (no duplicated list), byte-compares all pairs, walks both trees for orphans and undeclared directories; verified to catch stale copies, mirror hand-edits, and unlisted canonical files.
- `conversation_sync_test.go`: title precedence (parser title / base name / session lookup), chunk seq continuation and `fromLine` line-span offsets, images-after-text sequencing, empty-batch prune (delete vs mtime-only vs no-op), append base-seq against a seeded store.

## Validation

- Full test suite, `go vet`, and `gofmt` verified with CGO and FTS5 tags (`-tags "fts5 sqlite_fts5"`); the release gate re-runs them in CI before publishing.
- All changes passed a two-agent review (behavior-parity review plus a silent-failure audit) before landing.

## Upgrade notes

- Patch release: drop-in binary replacement. No config, index schema, or vector-space changes; no reindex required.
- After pulling this release on Windows, run `git status` once — the new `eol=lf` rules may mark the mirrored service scripts as modified until renormalized (`git add --renormalize tools skills`); content is unchanged.

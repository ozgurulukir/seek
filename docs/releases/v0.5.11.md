# seek v0.5.11

## Highlights

- **Faster reindex orphan cleanup:** stale-document deletion no longer scales as four round trips per document. Deletes are grouped into 500-id `IN` clauses, and the full-collection purge path (reindex) uses set-based subquery deletes.
- **Faster embedding runs:** each embedding API batch is persisted to SQLite in one transaction instead of one transaction per chunk, with the live HNSW/linear vector index updated incrementally for new chunks and rebuilt atomically when embeddings are replaced.

## Performance

- **Orphan cleanup (`internal/store.DeleteOrphansContext`):** the per-document loop issued `DELETE` statements against `fast_fields`, `documents_fts`, `chunks`, and `documents` one id at a time. Deletes now batch 500 ids per statement; a `nil` `livePaths` map (full purge) skips the id scan entirely and deletes by `collection_id` via subqueries. Partial purges keep live documents and their projections untouched; a repeat purge is a no-op. Covered by `TestDeleteOrphansContext` and benchmarks.
- **Chunk embedding writes (`internal/store`, `internal/pipeline`):** text, VL image, batch, and realtime embed paths now collect their batch into `store.ChunkEmbeddingUpdate` values and persist them with one prepared statement in one transaction. Vector-index handling mirrors the per-chunk contract: new IDs take the cheap incremental `Add` path; replacing an existing ID triggers an atomic off-to-the-side rebuild of the graph, and if that rebuild fails, previous embeddings are restored to SQLite — with restore failures now reported rather than swallowed.

## Refactoring

- **`seek auth login`:** prompts extracted into `promptProviderSelection`, `promptCustomProvider`, `promptAPIKey`, and `promptMultimodal`; `Run` is now a readable sequence of prompt calls. Behavior is unchanged (custom providers default to 1024 dimensions either way).

## Tests

- `TaskPrefixes`: uppercase nomic/e5/bge model names, explicit document-prefix override, empty-model fallback.
- `quoteQualifiedIdentifier`: embedded double quotes, multi-part names, empty identifier.
- Config defaults: all typed default constants (timeouts, permissions, chunking, HNSW params, compression, rerank) sanity-pinned.
- `SchemaRegistry.DefaultSchema`: zero-value registry, complete field definition set, call-to-call consistency.

## Validation

- Full test suite, `go vet`, and `gofmt` verified with CGO and FTS5 tags (`-tags "fts5 sqlite_fts5"`); the release gate re-runs them in CI before publishing.
- Every PR merged in this release passed its own CI (Linux + Windows) plus local targeted tests; squashed with conventional-commit titles.

## Upgrade notes

- Patch release: drop-in binary replacement. No config, index schema, or vector-space changes; no reindex required.
- Collections rebuilt with `seek collection reindex` after upgrading get the faster orphan-cleanup path; syncing/embedding gets the batched persistence automatically.

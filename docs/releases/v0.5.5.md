# seek v0.5.5

## Highlights

- Vector-space migrations now recreate the vector index with the configured
  embedding dimension before re-embedding.
- Failed migrations preserve the previous searchable state, including vector
  embeddings, FTS entries, fast fields, and the vector index.
- Rollback handling covers provider failures, cancellation, transaction errors,
  dimension mismatches, and legacy databases with nullable document metadata.
- Degraded embedding mode and intentionally skipped image chunks remain
  supported when a full vector rebuild is not required.

## Upgrade notes

This is a patch release. Existing installations can be upgraded with the
standard installer. Changing the embedding model or dimensions still requires
an explicit migration:

```text
seek collection reindex <collection> --allow-vector-space-change
```

# seek v0.5.8

## Highlights

- **ZCode conversation support:** a new embedded `zcode` parser schema indexes
  ZCode model-I/O rollout files (`~/.zcode/cli/rollout/*.jsonl`) — add it with
  `seek add --parser zcode`.
- The JSONL parser driver gained a **sliding-window mode** (`messages_path` +
  `offset_field`): rollout files carry a cumulative conversation window per
  request line, and the driver dedups messages by global index so every turn
  is indexed exactly once. Each line's `response.text` becomes the assistant
  turn.
- ZCode sessions can sync automatically via a manually configured `Stop` hook
  in `~/.zcode/cli/config.json` (see `docs/service.md`); no registry change or
  `seek hooks install` involvement.
- Documentation updated across the parser/service guides, README, and the
  bundled seek skill.

## Fixes

- CI: the Windows test job installs Zig from the renamed 0.16.0 archive
  (`zig-x86_64-windows-*.zip`); the previous URL 404'd and blocked the job.
- Test: the relative sync-path test skips when the temp dir and CWD live on
  different Windows drives instead of failing on `filepath.Rel`.

## Validation

- Full FTS5-tagged Go test suite, `go vet`, and `gofmt` are green on Windows
  (Zig CGO) and in CI on both ubuntu-latest and windows-latest.
- End-to-end: `seek add --parser zcode` detected 3 rollout files, embedded
  615 chunks through the local Ollama provider, and a hybrid search over the
  collection returned this session's own transcript with correct user and
  assistant turn attribution.
- Independent `code-reviewer` and `silent-failure-hunter` passes ran on the
  parser change; findings were fixed or explicitly documented (a few turns
  around a partial history compaction may be emitted twice — negligible for
  search scoring).

## Upgrade notes

Patch release; standard installer. To index ZCode history:

```bash
seek add --parser zcode
```

and optionally install the manual Stop hook from `docs/service.md`.
